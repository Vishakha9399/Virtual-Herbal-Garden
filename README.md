# Virtual Herbal Garden

Virtual Herbal Garden is an interactive React and Vite website for exploring medicinal and culinary herbs, understanding their uses and care requirements, and building a personal garden list.

## Features

- Browse an herb catalog by category
- View detailed herb profiles, prices, benefits, uses, and growing instructions
- Add and remove herbs from a personal garden saved in local storage
- Place herb orders through WhatsApp
- Responsive interface built for desktop and mobile devices

## Tech Stack

- React 18
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Radix UI and Material UI components
- Lucide icons

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

### Production build

```bash
npm run build
```

## Project Structure

- `src/app/components` – application pages and reusable components
- `src/app/data` – herb catalog data
- `src/app/utils` – application utilities, including WhatsApp ordering
- `src/styles` – global and theme styles
